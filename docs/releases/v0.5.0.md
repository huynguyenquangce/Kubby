# Kubby v0.5.0

This preview makes cluster problems easier to find and investigate. It adds
Health checks, a scheduling explanation for pending Pods, a read-only Cleanup
view, and a calmer Overview and button system.

## Highlights

- **Health checks** surfaces broken admission webhook backends, certificate
  expiry and trust problems, and resources stuck while terminating. Each result
  shows the evidence and a concrete next step.
- **Why Pending?** explains why an unscheduled Pod does not fit the available
  nodes, including resource, selector, taint and volume constraints. Open it
  directly from the Overview Attention queue or a Pod.
- **Cleanup** identifies unused resources and unpinned images with evidence and
  suggested commands. Kubby does not delete anything from this view.
- **Faster navigation** cancels superseded view reads when the view or namespace
  changes, so stale results cannot hold up the current screen.
- **Calmer UI** gives Overview panels their own content heights and uses a
  softer, consistent button hierarchy across the application. The issue queue
  keeps each Pod's next step visible without filling every row with strong blue.

## Download

Download `kubby-windows-amd64.exe` and
`kubby-windows-amd64.exe.sha256` from the assets below. Windows 11 normally
includes the required WebView2 runtime. Kubby needs a kubeconfig with the
permissions for the read and write operations you choose to perform.

## Preview limitations

- The Windows executable is not code-signed, so Windows SmartScreen may ask you
  to confirm the publisher before first launch.
- This prerelease publishes a Windows x86-64 binary only; source remains portable.
- Health checks and scheduling explanations use Kubernetes API evidence at the
  time of the request; they do not replace a live scheduler or admission trace.
- Browser automation does not prove native WebView2 clipboard, focus/paint, file
  dialog, ANSI rendering, or PTY resize behavior; those remain native checks.
- `govulncheck` reports GO-2026-5932 in Helm v3's linked legacy OpenPGP
  package, for which upstream has no fixed version. Kubby does not expose
  Helm's provenance-verification path, explicitly keeps
  `ChartPathOptions.Verify` disabled, and binds reviewed Helm writes to SHA-256
  preview digests; a regression test guards that boundary.
- Helm, Artifact Hub, and hosted AI providers require outbound network access.
