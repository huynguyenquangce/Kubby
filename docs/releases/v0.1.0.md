# Kubby v0.1.0

Kubby's first public preview: a native Windows desktop application for browsing,
troubleshooting, and operating Kubernetes clusters directly from kubeconfig,
without installing an in-cluster agent.

## Highlights

- Browse built-in resources and CRDs across namespaces and connected clusters.
- Inspect YAML, events, relations, logs, terminal sessions, and port forwards.
- Operate workloads through explicit confirmations and RBAC-aware controls.
- Manage Helm releases and repositories, search Artifact Hub, preview rendered
  changes, and pin installs to the exact chart archive that was reviewed.
- Optional resource-scoped AI diagnosis with local Ollama or a hosted provider;
  keys are write-only from the UI and evidence is redacted before preview/send.
- Responsive Overview snapshot, bounded live-log rendering, and linear-memory
  large-file diffs.

## Download

Download `kubby-windows-amd64.exe` and its `.sha256` file from the assets below.
Windows 11 normally already includes the required WebView2 runtime. Kubby needs
a kubeconfig with the permissions for the operations you choose to perform.

## Preview limitations

- The Windows executable is not code-signed yet, so Windows SmartScreen may ask
  you to confirm the publisher before first launch.
- This release publishes a Windows x86-64 binary only; source remains portable.
- `govulncheck` reports GO-2026-5932 in Helm v3's linked legacy OpenPGP package,
  for which upstream provides no fixed version. Kubby explicitly disables that
  verification path and uses SHA-256 preview/install binding instead.
- Helm, Artifact Hub, and hosted AI providers require outbound network access.
