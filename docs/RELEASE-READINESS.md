# Kubby 0.5.1 release readiness

Date: 2026-10-12

Scope: local preview candidate only. No tag or GitHub release was created.

## Result

The implementation and automated verification are ready for a native Windows
smoke check. The candidate is **not ready to publish**: this checkout contains
uncommitted source changes, the binary is intentionally identified as
`0.5.1-dev`, and the final Windows WebView2 UI has not been opened manually.
The dependency scanner also reports one upstream OpenPGP advisory without a
fixed version; Kubby disables Helm provenance verification and has a regression
test for that boundary.

## Implemented

- Corrected known scheduling verdicts for missing, deleting, Lost, and
  Immediate-Pending PVCs; unreadable StorageClasses stay unknown.
- Made log-follow completion and stop ownership safe across replacement
  streams, including the last buffered lines.
- Added provider HTTP contracts, credential redaction for provider errors and
  incident exports, private export file permissions, and clipboard result
  handling.
- Routed Helm defaults through the bounded, cancellable chart path; reject
  changed preview inputs and unsafe external links.
- Made Deployment rollback retry controller conflicts using a fresh object and
  reject replacement UIDs.
- Strengthened browser mocks, zoom coverage, AI/Helm/write lifecycle cases, and
  the opt-in disposable-cluster integration suite.
- Updated Go to 1.26.9 and patched dependencies that accounted for 11 findings
  in the initial Go advisory scan.

## Remaining release gates

1. Open this candidate on native Windows with WebView2 and complete the checks
   in [verification.md](../src/kubby/docs/verification.md), including startup,
   focus and zoom, clipboard/file dialogs, ANSI/PTY input, and tunnels. Record
   the result against this exact SHA-256.
2. Freeze and commit the intended release changes, confirm the release tag is
   unused, then build the clean commit with the exact version/commit/date
   identity and verify the release-named artifact using [BUILD.md](BUILD.md).
3. Repeat native Windows smoke verification against that final release-named
   artifact. Publish only after these gates pass; use prerelease status while
   the executable remains unsigned.

The advisory residual is limited to Helm's linked OpenPGP provenance code.
`configureChartSource` disables provenance verification, chart preview/install
binds to SHA-256, and `TestHelmOpenPGPVerificationRemainsDisabled` guards the
configuration. Keep this exception visible in release notes unless a fixed
upstream version becomes available.
