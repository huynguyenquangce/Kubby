# Changelog

All notable changes to Kubby are listed here, newest first. Each entry links to
the full release notes in `docs/releases/`, which are also the body of the
GitHub release. Versioning follows the rules in
[`docs/BUILD.md`](docs/BUILD.md#90-choose-the-version-number).

## [Unreleased]

## [0.5.1] - 2026-11-01

Maintenance preview: log-follow lifecycle, scheduling diagnosis and credential
handling fixes on top of v0.5.0. First release built by the Release workflow,
with a per-user Windows installer.
[Release notes](docs/releases/v0.5.1.md)

## [0.5.0] - 2026-10-01

Health checks, a scheduling explanation for pending Pods (Why Pending), a
read-only Cleanup view, and a calmer Overview and button system.
[Release notes](docs/releases/v0.5.0.md)

## [0.4.0] - 2026-09-13

NetworkPolicy isolation and route checks, logs from the previous container
instance, and previews of what a drain or manual scale will do before
confirming it.
[Release notes](docs/releases/v0.4.0.md)

## [0.3.0] - 2026-08-27

Evidence-first incident investigation, safer asynchronous workflows, faster
cluster exploration, stronger remote-input boundaries, and reliable operation
in narrow windows and at high WebView zoom.
[Release notes](docs/releases/v0.3.0.md)

## [0.2.0] - 2026-08-20

A clearer cluster overview, safer multi-cluster workflows, a real Pod terminal,
and UI coverage across desktop sizes and WebView zoom levels.
[Release notes](docs/releases/v0.2.0.md)

## [0.1.0] - 2026-08-11

First public preview: a native Windows desktop application for browsing,
troubleshooting and operating Kubernetes clusters directly from kubeconfig,
without an in-cluster agent.
[Release notes](docs/releases/v0.1.0.md)
